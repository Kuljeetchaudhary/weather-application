# 🌤️ Weather Application

A simple and responsive weather application built using **HTML, CSS, and JavaScript**. It uses the **OpenWeather API** to fetch and display real-time weather information for a searched city.

## 🚀 Features

* 🔍 Search weather by city name
* 🌡️ Displays current temperature
* 💧 Displays humidity
* 💨 Displays wind speed
* ☁️ Changes weather icon according to weather conditions
* 📱 Responsive and simple user interface
* ⚡ Fetches real-time weather data using an API

## 🛠️ Technologies Used

* **HTML5** — Structure
* **CSS3** — Styling and responsive design
* **JavaScript (ES6+)** — Functionality and API integration
* **OpenWeather API** — Weather data
* **Bootstrap** — UI components
* **Font Awesome** — Icons
* **Google Fonts** — Typography

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/Kuljeetchaudhary/weather-application.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Add your own OpenWeather API key in `script.js`:

```js
const api_key = "ENTER YOUR API KEY";
```

5. Search for a city to view its weather information.

## 🔑 API Key

This project uses the **OpenWeather API**.

For security, the API key is **not included in this repository**. You need to create your own API key and add it locally to `script.js`.
